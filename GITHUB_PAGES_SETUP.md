# Publish Cedarbridge on GitHub Pages

1. Create a **public** repository, ideally named `cedarbridge-digital-transformation`.
2. Upload the **contents** of this folder to the repository root (do not upload the ZIP as one file). Ensure `index.html` is at the top level.
3. Commit to `main`.
4. Open repository **Settings > Pages**; under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Check the **Visit site** link provided by GitHub Pages; validate the navigation to `app.html` and `analytics.html`.
6. The prototype stores demo requests in the browser's localStorage under that hosted site's origin; it does not share records between browsers, with the local file version, or with the analytics dashboard. **Only synthetic data.**

The independent project is a fictional training/portfolio simulation, not a commissioned client system, real production release or secure multi-user service. Formal business UAT remains outstanding. Do not add private CV files or real operational records.
